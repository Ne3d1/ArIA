# ArIA
Python IA

This project is made with AI, ChatGPT and Claude, but it is not made for nothing. With this project I want to demostrate that without having money to pay AI, you can make great projects with AI. 

Everything in this project is made with free plans of AI.

## Installation
### Linux
Extra ZIP `ArIA-vx.x.x`
Open a terminal in the folder

Run this comands:
- `./setup.sh`
- `./importar-corpus.sh` (v1.5 +)
- `./run.sh` or `./run.sh --cli` if you want terminal version

### Windows (only v1.7.2 windows fix +):
Extra ZIP `ArIA-vx.x.x`

Run this files:
- `setup.bat`
- `importar-corpus.bat`
- `run.bat`
